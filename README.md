# Гирлянда на STM32F407VGTx

В проекте пять режимов гирлянды и переключение между ними двумя клавишами штатной матричной клавиатуры. STM32 HAL и аппаратный I2C-периферийный блок не используются. Доступ к PCA9538 реализован собственным GPIO-драйвером: SDA и SCL переключаются программно на PB9 и PB8. Это сохраняет имеющееся подключение клавиатуры без HAL/I2C-драйвера.

> Важное уточнение: PCA9538 физически соединён с STM32 по линиям SDA/SCL. Поэтому при сохранении штатной проводки обмен с PCA9538 всё равно использует I2C-протокол, но реализован вручную через GPIO. Полностью отказаться от I2C-протокола и при этом оставить клавиатуру подключённой только к PCA9538 невозможно: матрицу нужно будет физически переподключить непосредственно к выводам GPIO микроконтроллера.

## Подключение

Четыре светодиода подключены к GPIOD: **PD12, PD13, PD14, PD15**. Это стандартные пользовательские светодиоды STM32F4 Discovery; если на конкретной плате они подключены иначе, поменяйте маску/выводы в `CustomDrivers/Src/gpio_driver.c`.

Штатная матричная клавиатура остаётся подключённой к расширителю PCA9538:

- **PB8** — SCL;
- **PB9** — SDA;
- адрес PCA9538 — `0x71` (адресные байты `0xE2` для записи и `0xE3` для чтения).

Клавиши верхнего ряда используются как кнопки управления: крайняя левая переключает режим назад, крайняя правая — вперёд. Центральная клавиша верхнего ряда не назначена. На типовой клавиатуре 4×3 это обычно клавиши `1` и `3`. Входы столбцов читаются с P4–P6 расширителя; строка верхнего ряда активируется через P0.

Программный опрос подавляет дребезг длительностью 25 мс. Не подключайте нагрузку со значительным током напрямую к GPIO: при необходимости используйте резисторы, транзисторные ключи или драйвер нагрузки.

## Режимы гирлянды

1. Один огонёк бежит по кругу.
2. Два соседних огонька бегут по кругу.
3. Попеременно загораются две пары светодиодов.
4. Светодиоды последовательно заполняются и гаснут в обратном порядке.
5. Все светодиоды мигают одновременно.

## Структура

- `CustomDrivers/Inc`, `CustomDrivers/Src` — самописные драйверы GPIO, тактирования, SysTick, кнопок, матричной клавиатуры и доступа к PCA9538 через GPIO.
- `Core/Src/main.c` — прикладная логика пяти режимов.
- `Drivers/CMSIS` и `Core/Startup` — стандартные определения регистров/ядра и стартовый код STM32F407.

Файл `SDK_LED.ioc` сохранён как справочный артефакт исходного проекта. Не запускайте генерацию кода CubeMX поверх этой реализации: она может восстановить HAL-инициализацию.

## Сборка

Откройте проект в STM32CubeIDE. Выбран STM32F407VGTx. Конфигурация тактирования пробует исходную схему с внешним HSE 25 МГц и PLL на 168 МГц; при недоступности внешнего генератора используется HSI 16 МГц. SysTick рассчитывается по фактической частоте ядра.
